# Computing Requirements

This workshop uses cloud-based Galaxy servers, so computationally heavy tasks run on remote infrastructure. However, a capable local machine is still needed to manage browser tabs, data uploads, and visualization tools simultaneously.

## Hardware

| Component | Minimum | Recommended |
| :--- | :--- | :--- |
| **Processor (CPU)** | Intel Core i5 / AMD Ryzen 5 | Intel Core i7 / Apple M1 or better |
| **Memory (RAM)** | 8 GB | **16 GB** |
| **Storage** | 10 GB free space | 20 GB+ (SSD preferred) |
| **Display** | 13" (1366×768) | 15" (1920×1080) |

## Software & Connectivity

- **Web Browser:** Google Chrome or Mozilla Firefox (latest version)
- **Internet connection:** Stable broadband required for Galaxy server access
- **Operating System:** Windows 10/11, macOS (Ventura+), or any modern Linux distribution

> **Note:** Participants must bring their **personal laptops**. Tablets are not suitable for the hands-on exercises.

## Galaxy Account

All participants must have an active account on a Galaxy server before the workshop begins. If you do not have one, register at [usegalaxy.org](https://usegalaxy.org) or the designated training server provided by the organizers.

## Tools Pre-installed on Training Server

The following tools will be available on the Galaxy training server:

| Tool | Purpose |
| :--- | :--- |
| **Velvet / SPAdes** | Short-read de novo assembly |
| **Flye** | Long-read de novo assembly |
| **QUAST** | Assembly quality assessment |
| **BUSCO** | Assembly and annotation completeness |
| **RepeatMasker** | Repeat element identification and masking |
| **RNA-STAR** | RNA-seq read alignment |
| **BRAKER3** | Gene prediction |
| **GFFread** | GFF/GTF file processing |
| **Helixer** | Deep learning–based gene prediction |
| **OMArk** | Proteome quality assessment |
| **JBrowse / WebIGV** | Genome feature visualization |
